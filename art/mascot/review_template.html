Every animation of the ink-blot detective, rendered from one 3D model into 64 px pixel art from eight directions. Pick an animation, turn the compass, change the floor, and watch it loop exactly as the game will play it.

Loading it in Phaser

this.load.multiatlas('smudge', 'smudge_atlas.json', 'assets/');
this.load.json('smudge_anims', 'smudge_anims.json');
// create()
this.anims.fromJSON(this.cache.json.get('smudge_anims'));
const smudge = this.add.sprite(160, 120, 'smudge').setScale(4);
smudge.play('walk_E');   // key = <animation>_<S|SE|E|NE|N|NW|W|SW>

Use pixelArt: true in the game config and integer scales only. The sprite's feet sit on row 60 of each 64 px cell; set the origin to (0.5, 0.94) to stand it on a floor line. Jump height is left to the engine.

# Stage cut, clear numbers, point out the liar: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fit The Midnight Fall into a 5-minute stage run, make every number readable, and replace its
cross-examination with one drag: evidence onto the liar.

**Architecture:** Game-only changes in `game/src`. A digits-only `@font-face` goes first in every font stack.
`LabFall` loses the gallery drop and stops using dialogue boxes during the drops. `CrossExam` gains a `point`
mode chosen by the case (`CaseDef.point`), so the other nine cases are untouched. `?judges` lowers the
interview gate to one suspect and skips slip-or-push.

**Tech Stack:** Phaser 3, TypeScript, Vite 5. No game unit tests exist; `npm run build` runs `tsc` and is the
check, plus browser runs in fixture and live mode.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-10-31-stage-cut-design.md`.
- Other nine cases behave exactly as before.
- Text lines on screen: 12 words or fewer.
- No server change; `python -m pytest -q` stays at 307 passed.
